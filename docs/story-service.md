# 서비스 맥락 (story-service)

> 출처: `docs/prd.md` v0.1 (2026-10-16)
> 확정: R1-A, 2026-10-16

## 유저스토리

1. 프로그램 담당 교사가 프로그램을 등록하고 공통 설문을 대상 학생에게 발행한다.
2. 학생이 D-day 카드에서 미응답 설문을 확인하고 응답을 제출한다.
3. 시스템이 설문 응답으로 생기부 초안(창체/진로/세특)을 자동으로 생성한다.
4. 담당 교사가 초안을 검토·수정한 뒤 확정한다.
5. 담임교사가 반 학생의 확정 기록·성적·상담을 권한 안에서 한 화면으로 열람한다.

## 어기면 안 되는 것 (판정 기준)

> 이 항목은 작업 흐름(story-work)의 재료가 아니라 **판정 기준**이다. R5 게이트에서 최소 1개 조건으로 사용한다.

| # | 규칙 | PRD 근거 |
|---|---|---|
| N1 | AI가 만든 초안은 교사가 확정하지 않으면 `finalized`가 될 수 없다. | §12 C10 |
| N2 | 교과교사는 다른 교사가 쓴 상담기록을 볼 수 없다. | §12 C6, §7 |
