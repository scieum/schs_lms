## 사용자 조정 값 (`rules/rules.yaml`)

글자수 기준은 하네스에 고정하지 않는다. 사용자가 `rules/rules.yaml`에서 직접 바꾸고, 판정 스크립트는 읽기만 한다. 에이전트는 이 파일을 수정할 수 없다.

| 키 | 의미 | 초기값 |
|---|---|---|
| `length.unit` | 세는 방식: `neis_bytes`(한글 3, 영문·공백 1) 또는 `chars`(공백 포함 글자) | `neis_bytes` |
| `length.max.<분류>` | 분류별 상한 (세특 / 창체-자율 / 창체-동아리 / 창체-진로) | 모두 1500 |
| `length.min_ratio` | 하한 = 상한 × 비율 | 0.6 |
| `style.endings` | 허용 문장 어미 | `함.` `음.` `임.` `됨.` `봄.` `힘.` |
| `reflect.min_matches` | 설문 반영 최소 명사 일치 수 | 2 |
| `retry.max` | S3 실패 시 S2 재시도 상한 | 3 |

초기값은 OI-5(NEIS 기준표)가 확정되기 전까지 쓰는 임시값이다.

**교사 분량 설정 (2026-10-16):** G2 ①의 상한·하한은 `input/program.json`의 `length`(교사가 정한 단위·최대)를 먼저 쓴다. 단, 최대는 `length.max.<분류>`를 넘을 수 없고(넘으면 상한으로 낮춤), 하한은 최대 × `length.min_ratio`다. `length`가 없으면 위 표의 값을 그대로 쓴다. 자세한 형식은 `harness-artifacts.md` "교사 분량 설정".
