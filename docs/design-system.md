## 원칙
1. **인디고가 주인공**: 주요 버튼, 선택 상태, 진행 막대, 차트 강조, 링크는 indigo-500.
2. **네이비로 무게**: 히어로, D1 헤더, 사이드바, 푸터는 navy(indigo-900). 검정은 쓰지 않는다.
3. **포인트는 작게**: 상태 색은 태그, 점, 차트 강조처럼 작은 면적에만 쓴다.
4. **색마다 뜻 하나**: 초록=완료, 주황=마감, 노랑=대기, 빨강=실패, 청록=새 소식.
