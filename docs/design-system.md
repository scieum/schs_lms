# 디자인 시스템 — 속초 인디고 (v2)

> 2026-10-16 확정 방향. 상세페이지 **B안 · 인디고**를 기준으로 앱 화면 전체에 적용한다.
> 이 문서가 시각 기준이다. 형태 규칙(알약·카드 24·그림자 없음 등)은 `docs/design-huddling.md`를 이어받고, 색은 이 문서가 우선한다.
> Figma: "디자인 시스템 · 속초 인디고" 페이지, Theme 컬렉션 `E 속초 인디고` 모드(53:0).

## 원칙
1. **인디고가 주인공**: 주요 버튼, 선택 상태, 진행 막대, 차트 강조, 링크는 indigo-500.
2. **네이비로 무게**: 히어로, D1 헤더, 사이드바, 푸터는 navy(indigo-900). 검정은 쓰지 않는다.
3. **포인트는 작게**: 상태 색은 태그, 점, 차트 강조처럼 작은 면적에만 쓴다.
4. **색마다 뜻 하나**: 초록=완료, 주황=마감, 노랑=대기, 빨강=실패, 청록=새 소식.

### Point (상태와 결정에만)
| 이름 | 진한 / 연한 | 변수 | 쓰는 곳 |
|---|---|---|---|
| Green · 완료 | #00B86B / #E3F8EE | status/success(-soft) | 확정, 충족, 출석, 생성 완료 |
| Orange · 마감 | #FF7A45 / #FFF1EA | brand/accent(-soft) | D-day, 마감 임박, 미응답 독촉 |
| Yellow · 대기 | #F5A524 / #FFF5E0 | status/warning(-soft) | 생성 중, 검토 대기, 예정 |

## 형태
- 모서리는 낮게: 카드 r12, 카드 안 블록 r10, 입력칸·버튼·탭·메뉴 r8, 태그·라벨 r6. 동그라미는 아바타·영랑이 버튼·단계 점만 (2026-10-16 "너무 둥글다" 피드백으로 낮춤). 입력칸은 채움만, 포커스 시 2px 인디고
- 그림자 없음. 예외: 네이비 히어로의 은은한 인디고 빛 번짐(상세페이지 B안)
- 띠(왼쪽 굵은 세로줄, 컬러 막대) 금지
- 단 나누기를 하면 좌우 단의 카드 높이를 맞춘다

## 글은 짧게 (2026-10-16)
- 넣지 않는 것: 경로 표시(빵부스러기), 헤더 부제, 카드 제목 아래 설명, 작은 회색 안내 문장
- 숫자는 큰 숫자 + 짧은 이름표, 목록은 제목 + 짧은 한 줄로 쓴다
- AI는 **AI 배너** 한 줄로 보여준다: "AI" 태그 + 제목 + 핵심 한 줄 + 버튼 하나(모바일은 화살표). 자세한 내용은 눌러서 본다
- 참고(유아이볼): 토스, 미니스탁, 보맵, 코빗, 세이브 AI 요약

## Do / Don't
- Do: 주요 행동은 화면당 인디고 버튼 1개 · 상태는 태그와 점 · 차트는 indigo-200 바탕에 강조 막대만 indigo-500
- Don't: 포인트 색으로 큰 면 칠하기 · 한 화면에 포인트 색 4가지 이상 · 빨강을 "중요" 강조용으로 쓰기(실패에만)
