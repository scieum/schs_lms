## 원칙
1. **인디고가 주인공**: 주요 버튼, 선택 상태, 진행 막대, 차트 강조, 링크는 indigo-500.
2. **네이비로 무게**: 히어로, D1 헤더, 사이드바, 푸터는 navy(indigo-900). 검정은 쓰지 않는다.
3. **포인트는 작게**: 상태 색은 태그, 점, 차트 강조처럼 작은 면적에만 쓴다.
4. **색마다 뜻 하나**: 초록=완료, 주황=마감, 노랑=대기, 빨강=실패, 청록=새 소식.

  - 프로그램 등록 4단계(모바일): "누가 참여하나요?" → 머리 줄 "반에서 고르기" + 엑셀로 넣기 → 반 칩 → (패널) → 이름 검색 → "고른 학생 15명" 칩(#EEF0FF + ×). PC는 4번 섹션 머리 "15명 선택" 오른쪽에 버튼, 검색칸 아래 패널. 단계 목록은 "대상 학생"이 지금 섹션.
  - 내 동아리: 카드 이름 "명단 엑셀로 올리기" → **"부원"**, 머리 오른쪽 버튼(예전 "이동반 명단 올리기와 같은 방식" 문구 뺌) → 패널 → "지금 부원 0명" + 빈 상자 "아직 없어요" → 흐린 "부원 저장"(넣기 전에는 누를 수 없음, 모바일은 꽉 참).
  - 누가기록: 학생 카드 머리 "학생 · 엑셀로 넣기 · 모두 선택", 그 아래 패널, 학생 목록은 그대로. 고를 수 있는 학생(내 반·동아리) 밖의 학번은 따로 세지 않고 **"못 찾음"에 함께** 들어간다.
- 참고(유아이볼): 제페토 문의하기(점선 첨부 칸 "파일 추가 또는 파일을 여기로 드래그") · 아하 전문가 신청(아이콘 + "첨부하기" 한 줄 칸, 허용 형식 안내 한 줄) · 메가MCG커피 문의하기("사진 불러오기" 칸 + 올린 파일 이름 × 칩) · 다글로·틈틈잇 파일 업로드(올리기 → 읽는 중 → 결과 흐름) · RailOne 예매(줄바꿈 칩 묶음, 선택 칩만 진하게).
