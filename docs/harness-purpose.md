# 하네스 목적 (harness-purpose)

> 확정: R2, 2026-10-16
> 기준 문서: `docs/story-service.md`, `docs/story-work.md`

## 매번 달라지는 것 (실행별 입력)

1. 프로그램 정보: 이름, 분류(창체 / 진로 / 교과), 개요
2. 대상 학생 명단
3. 설문 응답 파일 (CSV)
4. 학생별 희망진로

## 고정 (규칙 SSOT로 이동 예정 — R4)

- 공통 설문 4문항 (활동 내용 / 배운 점 / 느낀 점 / 후속 계획)
- NEIS 글자수 기준
- 생기부 문체 규칙

## 사용자

| 구분 | 누구 |
|---|---|
| 하네스를 돌리는 사람 | 프로그램 담당 교사 (본인) |
| 결과를 받는 사람 | 담임 |

## 완료 기준 (한 문장)

> 대상 학생 **N명 전원**에 대해 ① 응답이 있거나 미응답 사유가 기록되어 있고 ② 초안이 **글자수 한도 이내**이며 ③ 교사 확정 표시가 **N건**이고 ④ 담임 전달 파일이 **1개** 만들어졌다.

## 데이터 처리 원칙

- 하네스에는 **가명 처리된 파일만** 넣는다. 학번·이름은 가명 ID(`S001`, `S002` …)로 바꾼다.
- 가명 ID ↔ 실명 매핑표는 **하네스 폴더 밖**에 둔다.
- 판정: 하네스 입력 파일에서 5자리 학번 패턴과 명부 실명이 **0건**이어야 한다.
  (학번 자릿수는 속초고 실제 형식 확인 후 조정)
