# SCHS 나이스 입력 도우미 (크롬 확장 프로그램)

학생관리시스템에서 **확정한** 교과 세특·창체(자율·자치, 동아리, 진로)·행발을, 선생님이 로그인해 열어 둔 나이스 입력 화면에 학생별로 채워 넣는다.
**저장 버튼은 누르지 않는다.** 채운 내용을 확인하고 선생님이 직접 저장한다.

## 왜 확장 프로그램인가
나이스에는 외부에서 글을 써 넣는 공식 API가 없다 (Open NEIS API는 급식·시간표 같은 조회용).
그래서 상용 서비스(마이클 '나이스 커넥트' 등)처럼, 열려 있는 나이스 화면에 확장 프로그램이 값을 넣는 방식을 쓴다.

## 설치 (개발자 모드)
1. 학생관리시스템 › **나이스 입력** › **도우미 받기** → `neis-helper.zip` 압축 풀기
   (개발 중이면 이 폴더를 그대로 써도 된다. 파일을 고치면 `apps/web` 에서 `npm run pack:neis` 로 zip 을 다시 만든다)
2. 크롬 주소창에 `chrome://extensions` → 오른쪽 위 **개발자 모드** 켜기
3. **압축해제된 확장 프로그램을 로드합니다** → 푼 폴더(`schs-neis-helper`) 선택 → 퍼즐 아이콘에서 고정

## 사용 (v0.2)
1. 학생관리시스템 › **나이스 입력** → 보낼 기록 줄에서 **복사** (확정한 학생만 들어간다. 파일로 받아도 된다)
2. 나이스에서 해당 과목·반(또는 동아리·담임 반)의 입력 화면을 연다
3. 확장 아이콘 → **붙여넣기** → 반 고르기(동아리는 반을 고르지 않음) → 덮어쓰기/이어쓰기
4. 둘 중 하나
   - **한 번에 채우기**: 화면의 학생 줄을 이름으로 찾아 모두 채운다. 화면에서 이름을 하나도 못 찾으면(이름과 입력칸이 따로 그려지는 그리드) 보이는 입력칸에 확정 학생을 학번 순서대로 넣고 "순서대로 · 이름을 확인해 주세요"라고 알린다 (설정에서 끌 수 있음)
   - **한 명씩 넣기**: 나이스 화면 오른쪽 아래에 패널이 뜬다. 나이스 입력칸을 누르고 **넣기** → 다음 학생으로 넘어간다.
     화면 구조를 몰라도 되고, 누른 칸이 다른 학생 줄이면 넣지 않고 그 학생으로 옮겨 준다. **복사**로 손으로 붙여넣어도 된다
5. 파랗게 표시된 칸을 확인하고 **나이스 저장은 직접**

## 안전장치
- 학생 줄은 **이름**(같은 이름이 있으면 번호·반까지)이 맞을 때만 채운다 (설정에서 이름 확인을 끌 수 있음)
- 나이스 바이트(2026 기재요령: 한글 3, 영문·숫자·공백 1, 엔터 1)로 미리 세서, 넘는 학생은 채우지 않는다
- 불러온 자료는 브라우저 세션 저장소에만 두고 **30분 뒤 자동 삭제**, 브라우저를 닫아도 지워진다
- 서버로 아무것도 보내지 않는다. 권한은 `activeTab`(누른 탭만), `scripting`, `storage`, `clipboardRead`(붙여넣기 버튼을 누를 때만) 뿐

## 실제 나이스 화면에 맞추기 (처음 한 번)
나이스 입력 화면의 HTML 구조는 직접 볼 수 없어서, 기본값은 일반적인 표(`tr`)·입력칸(`textarea`) 기준이다.
안 채워지면:
1. 나이스 입력 화면에서 F12 → 학생 한 줄과 입력칸을 요소 선택으로 확인 (학생 이름이 보이지 않는 빈 화면이면 더 좋다)
2. 팝업 › **화면 찾기 설정**에 학생 줄 선택자 / 입력칸 선택자를 넣는다
3. 칸에는 보이는데 저장이 안 되면 **페이지 환경에서 실행**을 켠다 (그리드가 자체 이벤트로 값을 관리하는 경우)
4. 그래도 안 되면 F12에서 본 구조(이름은 지운 것)를 개발자에게 전달 → `fill.js` 선택자를 맞춘다

## 시험
`test/fake-neis.html` — 입력 이벤트로만 값이 바뀌는 가짜 입력 화면. 이 폴더를 `python -m http.server 3200` 으로 열고
`http://127.0.0.1:3200/test/fake-neis.html` 에서 확장을 실행하면 된다.

## 쓰기 전에 확인할 것
- 학교·교육청 정보보안 지침상 **개인이 만든 확장 프로그램을 나이스에 써도 되는지** 정보부에 확인한다
- AI는 초안까지만, 최종 문장은 교사가 확정한다 (PRD C10). 이 도구는 확정본만 넘긴다
