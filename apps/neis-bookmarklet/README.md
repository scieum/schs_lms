# SCHS 나이스 입력 버튼 (북마클릿)

학생관리시스템에서 **확정한** 교과 세특·창체(자율·자치, 동아리, 진로)·행발을, 선생님이 로그인해 열어 둔 나이스 입력 화면에 학생별로 채워 넣는다.
**저장 버튼은 누르지 않는다.** 채운 내용을 확인하고 선생님이 직접 저장한다.

크롬 확장 프로그램은 2026-10-19에 없앴다 ("헷갈리니깐 확장프로그램 자체는 아예 없애버리자"). 이 북마클릿 하나만 쓴다.

## 왜 북마클릿인가
나이스에는 외부에서 글을 써 넣는 공식 API가 없다 (Open NEIS API는 급식·시간표 같은 조회용).
그래서 열려 있는 나이스 화면 안에서 실행되는 북마크(북마클릿)가 값을 넣는다. 설치가 필요 없다.

## 쓰는 법
1. 학생관리시스템 › **나이스 입력** › ① "나이스 입력" 버튼을 북마크바로 끌어다 놓기 (안 되면 "다는 방법" › 주소 복사 → 새 북마크 주소에 붙여넣기)
2. 아래 목록에서 **복사** (확정한 학생만 들어간다)
3. 나이스 입력 화면에서 북마크 누르기 → 뜬 창에 **Ctrl+V** → 반·덮어쓰기/이어쓰기 → **한 번에 채우기** (또는 한 명씩 넣기)
4. **채운 뒤 대조** (v0.2.8~): 한 번에 채우기가 끝나면 나이스 칸을 다시 읽어 확정본과 견준다 — 일치 · 다름(덜 들어감 · 나이스에서 고친 글) · 못 찾음. 다른 줄을 누르면 차이 상자와 나이스 칸 빨강 테두리
5. **다른 것만 다시 채우기** → 다시 읽어 대조 → 다른 칸이 없으면 **흔적 지우기 하고 닫기** (창 자료 · 클립보드를 비우고 창을 닫는다. 나이스 칸에 채운 글은 그대로)
6. 채운 칸을 확인하고 **나이스 저장은 직접**
- **이동반 · 공동교육과정** (v0.2.9~): 반을 고르지 않는다 — 나이스 화면처럼 분반 학생이 학번순 한 목록(동아리와 같은 방식). 내보내기의 `moving` 으로 안다
- 버전이 바뀌면(앱 화면의 vX.Y.Z) 북마크를 지우고 다시 단다. 같은 화면에서 예전 버전 창이 떠 있어도 새 버전으로 바꿔 띄운다 (v0.2.7~)

## 채우는 순서
1. **나이스(eXbuilder6) 그리드에 바로 넣기** (`cpr-fill.js`, v0.2.6~): 2026-10-19 실제 나이스 동아리 화면에서 확인한 구조 — `cpr.core.Platform.INSTANCE` → 그리드 `grdMain` → 데이터 열 `stuFlnm`(성명) · `speclActSpablMteCn`(특기사항) · `length`(바이트). 성명으로 줄을 맞추고 `setCellValue`로 특기사항을 넣는다(나이스에서 직접 고친 것처럼 '수정됨'). 칸을 누르지 않아 클릭 한 번에 끝난다. 결과 줄: "그리드에 n명 채움". 선생님이 실제 나이스에서 확인함.
2. **화면 칸에 넣기** (`fill.js`): 그리드를 못 찾으면 학생 줄마다 있는 입력칸을 이름으로 찾아 채우고, 누르면 입력칸이 열리는 그리드는 이름 줄 높이의 칸을 눌러 열어 넣는다 (v0.2.5~). 이름을 하나도 못 찾으면 보이는 칸에 순서대로 넣고 "이름을 확인해 주세요"라고 알린다.
3. **한 명씩 넣기** (`panel.js`): 화면 구조를 몰라도 되는 방법. 나이스 입력칸을 누르고 '넣기'.

## 안전장치
- 학생 줄은 **이름**(같은 이름이 있으면 번호까지)이 맞을 때만 채운다
- 나이스 바이트(한글·한자 3, 영어·숫자·기호·공백 1, 엔터 1)로 미리 세서, 넘는 학생은 채우지 않는다
- **나이스 칸은 읽기만 한다** (대조): 그리드 데이터셋 값(`__schsCprRead`) 또는 화면 칸 글자(`__schsNeisRead`)를 읽어 창 안에서만 견준다. 저장 버튼은 누르지 않는다
- 기대값은 채울 때 만든 값(덮어쓰기 = 확정본, 이어쓰기 = 이전 글 + " " + 확정본). 줄바꿈(

)과 끝 공백은 무시한다
- 자료는 창이 열려 있는 동안 메모리에만 있다. **×로 닫거나 '흔적 지우기'**를 누르면 창 자료를 지우고 클립보드에 빈 글자를 쓴다(브라우저가 막으면 "클립보드는 못 비웠어요" 안내). 서버로 아무것도 보내지 않는다

## 고치기 · 시험
- 파일: `fill.js` · `cpr-fill.js` · `panel.js` · `bookmarklet/launcher.js`(창, 버전은 여기 `VERSION`). 고친 뒤 `apps/web` 에서 `npm run pack:neis` → `src/lib/neis-bookmarklet.ts` 가 다시 만들어진다
- 시험 화면: `test/fake-neis-exbuilder.html`(나이스 eXbuilder6 흉내 · 대조 시험용으로 '이하늘' 칸은 처음 채울 때 끝 6글자가 잘린다, `?cut=0`이면 끔) · `test/fake-neis-grid.html`(이름 표·특기사항 표 분리, 누르면 입력칸) · `test/fake-neis.html`(일반 표). 이 폴더를 `python -m http.server 3301` 로 열고 북마클릿 코드를 실행해 본다

## 쓰기 전에 확인할 것
- 학교·교육청 정보보안 지침상 나이스 화면에서 북마클릿을 써도 되는지 정보부에 확인한다
- AI는 초안까지만, 최종 문장은 교사가 확정한다 (PRD C10). 이 도구는 확정본만 넘긴다
